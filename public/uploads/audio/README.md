# Audio files

Audio files are intentionally excluded from this package because of their size.

Copy the original PulseWave `audio` files into this directory without changing
their filenames. The database already points to paths such as:

- `uploads/audio/papi.opus`
- `uploads/audio/I_Really_Like_You.flac`
- `uploads/audio/apt.mp3`

The site interface and catalog remain usable when audio files are absent, but
the player will show an unavailable-audio message when playback is attempted.
